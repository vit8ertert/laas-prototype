# LAAS prototype

A coded, clickable prototype of LAAS, an artist platform for running a band: gigs, contacts, money and releases.

**Open it:** https://vit8ertert.github.io/laas-prototype/

Use the **Flows** button in the top bar to jump to a flow: first run, booking a gig, a booking's life, getting paid,
gig day, importing contacts, a release, themes and settings.

Plain HTML, CSS and JavaScript in one file (`index.html`), no build step. The band, venues and people are example data.
